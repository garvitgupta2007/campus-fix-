# CampusFix — Simple SIH Frontend

This is Version 1 of the Smart Campus Complaint & Maintenance System.

## Run
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in Chrome/Edge.
3. No Node.js, React, database, or internet connection is required.

## What works
- Dashboard
- Raise complaint form
- New complaints appear immediately in My Complaints
- Search complaints
- Filter by status
- Campus blueprint preview
- Responsive layout

## Important
This is frontend-only. Data disappears when the page is refreshed.
